# 摄动模型与数值方法

## 两种外推模式

`propagator.mode` 可取：

- `two_body`：解析开普勒外推。仅含中心引力，平近点角按
  n = √(μ/a³) 线性推进，再做开普勒↔笛卡尔转换。用于验证守恒性。
- `j2`（默认）：轴对称地球的 J2 重力场。

## J2 动力学

密切状态在惯性系中按

```
r̈ = -μ r / r³ + J2 项
```

积分，其中 J2 加速度为标准的轴对称二阶带谐项（见
`orbit_service/propagator.py::_j2_acceleration`）。

- 积分器：定步长四阶 Runge–Kutta（RK4）。
- 默认步长 `step_seconds = 15 s`。
- 时间区间被均分为整数步，因此同一目标时刻的积分路径与结果**逐位确定**，
  与并发、调用顺序无关。

## 平均根数到密切根数

J2 模式在历元将平均根数转为密切笛卡尔状态，采用 Kozai 一阶短周期改正
（径向/迹向/法向 RSW 三分量，见 `_mean_to_osc`）。TLE 与 COE 两条输入
路径最终汇入同一组平均根数，因此描述同一轨道时结果一致。

## 扫描与求根

可见窗口与地影事件使用“固定步长扫描 + 对分求根”：

- 扫描步长 ≤ min(60 s, 轨道周期/16)，保证不会漏掉一次过境或一次地影；
- 边界用对分收紧到 `boundary_tolerance_seconds`（默认 1×10⁻⁴ s）；
- 收紧容差只让边界单调内移，窗口不会新增、丢失或乱序。

## 精度配置

在请求体的 `propagator` 对象中可配置：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `mode` | `j2` | `j2` 或 `two_body` |
| `step_seconds` | 15 | RK4 固定步长，越小越精确、越慢 |
| `rtol` / `atol_metres` | 1e-10 / 1e-6 | 预留的容差配置 |
| `max_steps` | 200000 | 单次积分最大步数，超出显式报错 |

RK4 为四阶收敛：以 1 s 步长结果为基准，近地轨道 2 天外推的位置差在
步长 60 s 时约数千米、30 s 时约 200 m、**15 s 时约 8 m**、5 s 时约
0.05 m。默认 15 s 满足文档约定的 50 m/2 天容差；需要更高精度可调小步长。
