# 摄动模型

服务提供两种轨道外推模式，通过 `perturbation` 字段选择：

* `none`：纯二体（开普勒）解析外推，用于能量/角动量守恒校验。
* `j2`（默认）：**J2 一阶长期摄动 + 短周期修正**的平均根数解析传播器。

## 二体模式

由历元根数与平运动 `n = sqrt(μ/a³)` 线性推进平近点角
`M(t) = M₀ + n·Δt`，再经开普勒方程 `E − e·sin E = M` 转换为
J2000 直角坐标状态。预报区间内轨道能量 `ε = v²/2 − μ/r` 与
角动量 `h = |r × v|` 的漂移仅为浮点舍入（< 1e-3，见
`tests/test_propagation.py::test_two_body_energy_angular_momentum_drift_bounded`）。

## J2 长期（secular）速率

对平均根数采用 Kozai/Brouwer 一阶长期速率（Vallado 式 8-46 系列）：

```
Ȯ = -(3/2) n J2 (Re/p)² cos i
ω̇ =  (3/4) n J2 (Re/p)² (5 cos²i − 1)
Ṁ = n + (3/4) n J2 (Re/p)² √(1−e²) (1 − 3 cos²i)
```

其中 `p = a(1−e²)`，`n = √(μ/a³)`。半长轴、偏心率、倾角无长期变化。
在输出直角坐标状态前叠加 J2 一阶短周期位置/速度修正（RSW 坐标系，
径向/沿迹/法向），消除大部分每圈周期振荡。

## 独立参考传播器

`app/reference.py` 提供**与解析传播器完全独立**的参考实现：在 J2000 直角坐标
状态上以固定步长经典 RK4 直接积分

```
r̈ = −μ r/|r|³ + a_J2(r)
```

其中 `a_J2` 为标准二阶带谐加速度。初始条件来自同一套二体根数→状态转换，
但两者不共享任何外推代码（仅共享物理常数）。测试中以 10 s 步长（24h 自洽
收敛误差 < 200 m）作为独立参考轨道。

## 精度与适用范围

该解析 J2 模型为**一阶平均根数模型**，与完整 J2 数值积分之间存在有界的
残差（短周期高阶项、平均/密切元素约定差异）。约定容差见
[accuracy.md](accuracy.md)。适用于：

* 近圆到中等偏心率的近地轨道（LEO）；
* 数小时到数天量级的预报；
* 地面站可见窗口、地影事件等工程估算。

不适用于：长时间（数周以上）高精度预报、大偏心率深空轨道、需要
阻力/光压/日月摄动的场景。
