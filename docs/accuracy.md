# 精度契约与容差

本文件给出可复现的精度约定与对应自动化测试。所有容差均为代码中强制执行的
断言阈值，修改模型时测试会捕获退化。

## 时间一致性

* 同一时刻的 ISO 8601 字符串与 Unix 时间戳输出状态完全一致
  （位置差 < 1e-6 m）。
* J2000 历元儒略日误差 < 1e-9 天；GMST 与 280.4606° 参考值差 < 1e-3 度。

## 二体模式（无摄动）

| 量 | 72 小时上界 |
|----|-------------|
| 轨道能量漂移 | < 1e-3 J/kg |
| 角动量漂移 | < 1e-3 m²/s |

## J2 模式 vs 独立 RK4 参考轨道

参考：`app/reference.py`，J2 直角坐标 RK4，10 s 步长（其 10 s vs 30 s
自洽收敛在 24h 内 < 200 m）。

| 场景 | 位置误差上界 |
|------|----------------|
| 典型 LEO（a=7000 km, e=0.001, i=51.6°），72 h | **25 km** |

残差为**有界振荡**（随时间次线性增长），主要来自一阶短周期高阶项与
osculating/mean 元素约定差异，而非趋势性相位漂移。该量级与“仅含 J2 的
一阶解析平均根数模型”的理论精度一致。

> 说明：本服务的 J2 模型是解析平均根数模型，不是 SGP4/SDP4，也不是
> 高精度数值星历。25 km / 72h 的容差是**模型级**容差；如需十米级精度，
> 应直接使用 `app/reference.py` 的数值积分器或接入 SGP4。

## TLE 与经典根数一致性

TLE 平根数（WGS-72）转换为经典根数时：

* 半长轴由平运动 `n` 经 `a = (μ/n²)^(1/3)` 反算，往返误差 < 1e-6 m；
* 倾角/RAAN/ArgP/M 角度为度→弧度精确换算；
* 转换后根数与直接以相同经典根数构造的轨道在**同一历元、同一 μ**
  下状态一致（< 1 mm，因为二者走同一条根数→状态路径）。

注意：TLE 使用 WGS-72 常数（μ=3.986008e14 m³/s², Re=6378135 m），
经典根数 API 默认使用 WGS-84/EGM96（μ=3.986004418e14）。两套常数的
μ 差异约 1e-6，跨常数比较时需显式指定 `mu`，这属于物理常数约定差异，
不是换算错误。

## 可见窗口边界精度

* 边界用二分法求解，可配置 `boundary_tol_s`（默认 1 s）。
* 收紧容差时边界单调收敛到稳定值，不出现跳变、窗口丢失或顺序错乱
  （`test_boundary_converges_and_stabilizes`）。
* 采样步长 `sample_step_s`（默认 60 s）决定最短可检测过境；
  更短过境需更小步长（文档与参数说明中提示）。

## 地影

圆柱与锥形模型在 LEO 的累计地影时长相对差 < 2%（12h 统计），
差异来源见 [shadow.md](shadow.md)。

## 退化与非物理输入

* 近圆轨道（e→0）、大偏心率（e=0.85）外推不产生 NaN；
* e ≥ 1、半长轴过低导致近地点低于地表等输入显式失败，
  返回 `FIELD_OUT_OF_RANGE` / `NON_PHYSICAL_ORBIT`。
