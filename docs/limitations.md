# 已知限制

1. **不实现完整 SGP4/SDP4**。TLE 被转换为 J2 平均根数后用本服务自己的
   J2 数值积分外推；TLE 的 BSTAR、阻力导数等字段被解析校验但不参与动力
   学。长弧（多日）结果会与基于 SGP4 的官方星历产生系统差。
2. **仅 J2 摄动**。不含 J3/J4、日月引力、太阳光压、大气阻力、潮汐与
   相对论效应。
3. **坐标框架为自洽的 J2000-like 惯性系**，不实现 IAU 2006 岁差章动与
   极移；UT1−UTC、闰秒被忽略。
4. 太阳历书为低精度解析模型，地影边界精度以服务自身模型为准，不用于
   食甚时刻的精密预报。
5. 仅支持**束缚椭圆轨道**（0 ≤ e < 1）；抛物线/双曲线轨道显式拒绝。
   近地点低于地球半径的轨道显式拒绝。
6. 可见窗口与地影扫描依赖固定扫描步长（≤ 周期/16），对持续时间异常短的
   事件理论上存在漏检可能；常规近地轨道过境/地影持续数分钟，安全裕度
   充足。
7. 数值积分为定步长 RK4，极窄椭圆或要求厘米级以上精度时应自行调小
   `step_seconds`。
