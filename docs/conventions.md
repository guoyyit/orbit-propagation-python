# 时间系统与坐标约定

本文件规定本服务所有输入、计算与输出使用的时间系统、参考框架与单位。

## 单位

| 量 | 单位 |
|----|------|
| 长度 | 米 (m) |
| 速度 | 米/秒 (m/s) |
| 时间（内部） | 秒 (s)，历元为 UTC `datetime` |
| 角度（内部/经典根数 API） | 弧度 (rad) |
| 角度（TLE） | 度，解析后转换为弧度 |
| 仰角/地理坐标（HTTP 输入输出） | 度 (deg) |

## 时间系统

* **输入一律视为 UTC**。
  * ISO 8601 字符串支持 `Z` 或显式偏移（如 `+08:00`）；不带偏移的朴素时间按 UTC 处理。
  * Unix 时间戳为自 `1970-01-01T00:00:00Z` 起的秒（浮点，可为负）。
  * 同一时刻的 ISO 字符串与 Unix 时间戳产生**完全一致**的结果（有测试覆盖）。
* **儒略日（JD）** 由 UTC 历元换算，内部以 **UT1 ≈ UTC** 近似（忽略 DUT1，见“已知限制”）。
* **地球力学时 TT** 用于恒星时计算，采用常量
  `TT − UTC = 69.184 s`（J2000 闰秒体系，1972–2100 内误差为毫秒级）。

## 参考框架

* **惯性系**：J2000（EME2000，地心天球参考系）。所有位置/速度状态均在 J2000 下给出，
  HTTP 字段名为 `position_j2000_m`、`velocity_j2000_m_s`。
* **地固系**：ECEF/ITRF 风格，由绕 z 轴旋转格林尼治平恒星时（GMST）实现。
  **忽略岁差、章动与极移**（J2000 与 ITRF 的 z 轴、春分点差异被忽略），
  这对地面站可见性的影响在亚公里量级，见“已知限制”。
* **GMST** 采用 IAU 1982 序列（Vallado 式 3-45），J2000 历元校验值
  280.4606°。
* **地面站**：WGS-84 大地纬度/经度/海拔，用标准椭球公式转 ECEF。
* **当地坐标系**：站心 ENU（东-北-天），仰角为相对当地水平面的夹角。

## 轨道根数

经典轨道六根数（Keplerian）：

1. 半长轴 `a`（米）
2. 偏心率 `e`（0 ≤ e < 1，仅支持有界轨道）
3. 轨道倾角 `i`（弧度，0 ≤ i ≤ π）
4. 升交点赤经 `Ω`（弧度）
5. 近地点幅角 `ω`（弧度）
6. 历元平近点角 `M`（弧度）

根数参考历元为 `epoch`（UTC）。TLE 的平根数（WGS-72）转换后使用相同的字段，
但引力常数采用 WGS-72 的 `μ`（详见 [accuracy.md](accuracy.md)）。

## 已知限制

* UT1 与 UTC 的差值（DUT1）被忽略；TT−UTC 固定为 69.184 s，不随日期更新闰秒。
* 地固/惯性变换只含 GMST 绕 z 轴旋转，忽略岁差、章动、极移。
* 太阳位置为低精度平黄经模型（~0.01°），用于地影判定；不用于精密定向。
* 仅建模地球中心引力与 J2 带谐项；不含大气阻力、太阳光压、三体引力、J3+ 项。
  TLE 中的 `bstar`、`ndot`、`nddot` 会被解析校验，但不参与动力学积分。
