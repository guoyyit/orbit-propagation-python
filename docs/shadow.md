# 地影模型

服务计算卫星进入/离开地球本影（umbra）的事件与累计光照时长，提供两种
几何模型：

## 圆柱模型（`cylindrical`）

把太阳视为**无限远、角半径为零**的平行光源。地影是半径等于地球赤道半径
`R_E = 6378137 m` 的无限长圆柱，轴向与太阳方向相反。

判定：设卫星位置 `r`，太阳单位方向 `ŝ`（地心→太阳），

* 沿太阳方向投影 `r·ŝ ≥ 0`：在向阳半球，恒为光照；
* `r·ŝ < 0` 且到阴影轴的垂直距离 `ρ ≤ R_E`：在本影中。

优点：简单、无锥形末端，任何高度都可判定。
缺点：忽略太阳有限角半径（约 0.2666°），在低轨每次进出影时刻有几秒偏差。

## 锥形模型（`conical`，默认）

考虑太阳有限半径 `R_S = 6.957e8 m` 与日地距离 1 AU。地球本影是一个
**收敛圆锥**，锥角

```
tan θ = (R_S − R_E) / AU
```

在地球背阳面距离 `d` 处，本影半径为

```
R_umbra(d) = R_E − d · tan θ
```

当 `R_umbra ≤ 0`（约 1.4e9 m 之外，远超 LEO）本影锥结束，恢复全光照。
卫星 `ρ ≤ R_umbra(d)` 时位于本影。

## 两种模型的差异

* 在 LEO，锥形本影半径比圆柱略小，因此卫星**更早出影、更晚进影**，
  每次边界相差几秒，累计地影时长相对圆柱模型偏小。
* 12 小时统计下，两者累计地影时长相对差 **< 2%**（有测试覆盖）。
* 差异在低轨很小（太阳角半径小）；高轨差异增大，且锥形模型在本影锥
  末端之外正确地不再判定为地影。

## 半影（penumbra）

锥形几何同时存在半影区。当前实现**检测本影边界**，半影按“光照”处理
（`illumination_fraction` 返回 0/1 指示量）。因此事件序列给出的是
进/出**本影**的时刻，不含半影渐变。光照时长 = 区间总长 − 本影时长。
这是已知简化，足以支撑“是否被地球遮挡”的可见性/光照工程判断。

## 太阳位置

太阳位置用低精度平黄经模型（Vallado Alg. 29，黄赤交角 23.439291°，
圆轨道 1 AU），精度约 0.01°，对应地影边界约数秒，与圆柱/锥形差异同量级。
