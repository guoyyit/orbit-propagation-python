# 地影模型与光照事件

服务提供两种地球阴影模型，用 `shadow_model` 选择：

## 圆柱模型（`cylindrical`）

把地球视为遮挡一个无限长、半径等于地球赤道半径 Rₑ 的圆柱阴影，阴影轴沿
反太阳方向。判定：

- 卫星在太阳一侧（轴向投影 ≥ 0）：有光照；
- 否则比较卫星到阴影轴的垂直距离与 Rₑ。

该模型忽略太阳有限视半径，几何简单，阴影无限长。

## 锥形本影模型（`conical`）

用太阳有限角半径（约 0.2666°）构造真正的锥形本影：

- 本影锥沿反太阳方向收窄，在距地心
  L = Rₑ / sin θ（θ 为太阳与地球视半角之差）处收缩到顶点；
- 在锥内任意深度处，阴影半径
  R_shadow(z) = Rₑ − z·sin θ；
- 卫星到轴的垂直距离小于该深度处阴影半径即在本影中。

## 两种模型的可解释差异

锥形本影比圆柱阴影**更短、更窄**，因此对同一条轨道：

- 锥形模型的**进影更晚、出影更早**；
- 锥形模型的**累计地影时间更短、累计光照时间更长**；
- 事件时刻与数量一一对应，差异在近地轨道通常为每次地影数秒到十几秒量级。

圆柱模型是锥形模型在“太阳视为无限远点光源”近似下的保守上界，适合工程上
最坏情形的光照估计；锥形模型更接近物理真实。自动化测试
`test_conical_eclipses_are_shorter_than_cylindrical` 守护这一方向关系。

太阳位置使用低精度几何历书（平黄经 + 中心差、J2000 平黄赤交角），日距
精度约 1%、方向精度约 1°，远低于 LEO 地影边界对太阳方向的敏感度要求。
