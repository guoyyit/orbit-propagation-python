# 时间系统与坐标约定

## 单位

所有内部计算使用 SI 单位：米、秒、弧度（质量不参与计算）。输入的经典轨道根数
（COE）可通过 `angles: "degrees"` 选择以角度提交，默认弧度。HTTP 输出中的
角度（如仰角）以度表示，并在字段名中带 `_deg`。

## 时间系统

- 内部时刻统一表示为 POSIX 时间戳（自 1970-01-01T00:00:00Z 起算的连续浮点
  秒），即 UTC 民用时，忽略闰秒（POSIX 时间尺度）。
- HTTP 入参的 `time`、`start`、`end`、`epoch` 同时接受：
  - ISO 8601 字符串，如 `2024-01-01T00:00:00Z`（`Z` 或显式偏移；无时区的
    朴素时间戳按 UTC 解释）；
  - Unix 秒，数值或数字字符串。
- 两种形式解析到同一 `Epoch` 后逐位一致（浮点相同）。
- 格林尼治平恒星时（GMST）采用 IERS 常用多项式，以 UTC 近似 UT1，误差远
  小于本服务的米级容差。

## 坐标框架

- 惯性框架：以 J2000 平赤道/平春分点为目标的右手地心系（x 指向春分点、
  z 沿自转轴），输出字段标注为 `ECI_J2000_LIKE`。本服务不绑定 IAU 精确
  岁差章动模型，框架由 GMST 与地固系自洽定义，地面站旋转与轨道积分使用
  同一组常量，因此内部结果严格自洽。
- 地固系：WGS84 大地坐标（纬度、经度、海拔）转 ECEF，再经 GMST 绕 z 轴
  旋转到惯性系。
- 位置/速度向量在同一惯性系中给出。

## 轨道根数

经典六根数：半长轴 a（米）、偏心率 e、轨道倾角 i、升交点赤经 Ω、
近心点幅角 ω、平近点角 M（后四个默认弧度）。输入的根数被定义为 **J2
平均根数**；在 J2 模式外推时先施加一阶 J2 短周期改正得到密切根数再做
数值积分。
